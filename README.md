# Best-Face

Автоматический отбор лучшего фото из серий. На вход — папка с фотографиями
(несколько кадров каждого человека вперемешку), на выход — по одному лучшему кадру
на человека: серьёзное лицо, смотрящее ровно в камеру, с открытыми глазами, резкое
и наиболее «узнаваемое» для систем распознавания лиц.

## Быстрый старт (без git и командной строки)

1. **Скачайте программу.** На странице репозитория нажмите зелёную кнопку **Code → Download ZIP**
   и распакуйте архив в любую папку (git не нужен).
2. **Установите Python 3.10 или новее** с [python.org/downloads](https://www.python.org/downloads/).
   В установщике Windows обязательно отметьте галочку **«Add python.exe to PATH»**.
3. **Запустите на своей папке с фото.**
   - **Windows:** перетащите папку с фотографиями на файл `run.bat`.
   - **macOS:** двойной клик по `run.command` и выбор папки в диалоге (один раз в Терминале: `chmod +x run.sh run.command`).
   - **Linux:** `./run.sh "путь/к/папке"` (один раз: `chmod +x run.sh`).
4. **Подождите при первом запуске.** Скрипт сам создаст окружение `.venv`, установит нужные пакеты
   и **докачает модель распознавания лиц `w600k_mbf.onnx`** (13 МБ) в папку `models/` (она создаётся
   автоматически). Остальные модели уже лежат в репозитории. Нужен интернет, это займёт несколько минут.
   Последующие запуски быстрые.
5. **Заберите результат** в папке `best_face_output` внутри вашей папки с фото:
   лучшие кадры — в `best/`, подробности — в `report.json`, обзор с превью — в `contact_sheet.html`
   (откройте в браузере; если хотите изменить выбор, кликните по нужному кадру, нажмите «Скачать
   manual_choices.json» и **перетащите этот файл на `run.bat`**: подробности ниже).

Если что-то пошло не так, текст ошибки и подсказка остаются в окне. Частые причины: не найден Python
(переустановите с галочкой PATH), нет интернета при первом запуске (запустите ещё раз).

## Как это работает

1. Детекция лица (YuNet, OpenCV) и выравнивание по 5 точкам.
2. Эмбеддинги: ArcFace `w600k_mbf` (512-dim) для группировки; опционально Human FaceRes (1024-dim) для метрики узнаваемости.
3. Группировка кадров: среднее сцепление (average-linkage) по cosine-сходству с поправкой на время съёмки (EXIF). Режим `person` (по умолчанию) собирает все кадры человека в один кластер и выбирает один лучший кадр на человека, даже если его снимали несколько раз; режим `series` сначала режет папку на серии по паузам в съёмке (EXIF), затем разделяет людей внутри серии и выбирает лучший кадр на каждую серию.
4. Метрики качества кадра: резкость, фронтальность и поза головы (yaw, pitch и наклон по MediaPipe), открытость глаз (EAR + blink + squint), **взгляд в камеру**, **нейтральность выражения** (улыбка, открытый рот, брови), размер лица, экспозиция, уверенность детектора, близость к центру серии, эстетика лица (NIMA).
5. Жёсткие фильтры + взвешенная сумма → лучший кадр. Веса и пороги — в `config.yaml`.
6. Результат: `best/` (лучшие кадры), `rejected/`, `report.json` и HTML-контактный лист `contact_sheet.html`.

Персоны (серии) нумеруются в порядке исходной папки — по лучшему кадру.

### Кэш и скорость

Результаты первого этапа (детекция, эмбеддинги, метрики) кэшируются в `<папка результатов>/frame_cache.npz`.
Повторный запуск с другими порогами или весами занимает секунды. Кэш сбрасывается при смене моделей или параметров детекции
и пропускается ключом `--no-cache`. Чтение JPEG идёт в потоках (`performance.workers` в конфиге).

### Контроль и подбор весов

В `contact_sheet.html` есть фильтр «только сомнительные» (близкие по score кадры, подозрение на склейку разных людей,
низкое качество). Кликом по превью можно выбрать лучший кадр вручную; выбор скачивается как `manual_choices.json`.
По таким выборам `tune_weights.py` обучает веса скоринга:

```bash
python tune_weights.py "<результаты>/report.json" manual_choices.json
```

Чтобы подставить ручной выбор в результат (`best/`, отчёт, контактный лист), **перетащите скачанный `manual_choices.json` на `run.bat`**
(на macOS и Linux: `./run.sh "путь/к/manual_choices.json"`). Никаких ключей не нужно: путь к папке с фото и папке результатов записан
в самом файле, программа возьмёт их оттуда и сама применит выбор. Если нужно, то же самое можно сделать и так:
`python best_face.py manual_choices.json` или `python best_face.py "папка_с_фото" --choices manual_choices.json`.
Выбор привязан к имени файла, поэтому остаётся верным и после смены настроек. Благодаря кэшу перезапуск занимает секунды.
Файл, скачанный из контактного листа старой версии (без папок внутри), перетаскиванием работать не будет: откройте обновлённый
`contact_sheet.html` (запустите программу на папке с фото ещё раз) и скачайте файл заново.

### Большие папки и устойчивость

- При числе кадров больше `clustering.dense_limit` режим `person` работает в два этапа (кластеризация по временным сегментам и слияние центроидов), чтобы не строить матрицу n×n.
- Приоритет отбора — серьёзное лицо, смотрящее ровно в камеру. Для этого из MediaPipe берутся: взгляд (радужка и `eyeLook*`, с поправкой на поворот головы), нейтральность выражения (улыбка, открытый рот, поднятые брови, растянутые губы — штраф) и поза головы (гладкий штраф за yaw, pitch и наклон к плечу). Кадр выбывает, если он заметно хуже лучших кадров этого же человека по глазам, взгляду или мимике (`max_eye_gap`, `max_gaze_gap`, `max_expr_gap` в `config.yaml`) и есть из чего выбрать; открытый рот (`max_jaw_open`) отсеивается жёстко. Если все кадры серии с улыбкой, выбирается наименее улыбающийся.
- Прежние файлы `personNNNN_*` из `best/` при повторном запуске **не удаляются**, а переносятся в `best_prev/<время>/` (хранятся 3 последние копии): если вы дополняли имена файлов вручную, эта работа не пропадёт.
- В отчёте помечаются персоны с единственным кадром (`single_frame`).

## Установка (вручную)

Если вы не пользуетесь `run.bat` / `run.sh`. Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python download_models.py
```

В окружении должен быть **один** пакет OpenCV: `opencv-contrib-python` (его же требует mediapipe). Если в вашем окружении
уже стоят `opencv-python` или `opencv-python-headless`, удалите их (`pip uninstall -y opencv-python opencv-python-headless`) и поставьте
`opencv-contrib-python`: два пакета пишут в один модуль `cv2` и мешают друг другу. Программа предупредит об этом при запуске.
Скрипты `run.bat` / `run.sh` создают чистое окружение `.venv` и этой проблемы не имеют.

На Windows ставится `onnxruntime-directml` (GPU AMD/Intel/NVIDIA), на macOS и Linux — `onnxruntime`.
Для CUDA на NVIDIA замените пакет на `onnxruntime-gpu` (в окружении должен быть **только один** пакет `onnxruntime*`).
Принудительный выбор провайдера: переменная `BEST_FACE_PROVIDER=cpu|cuda|dml|coreml`.

### Модели

Основные модели **уже лежат в папке `models/` репозитория**, ничего скачивать вручную не нужно.
Исключение — `w600k_mbf.onnx` (ArcFace): её лицензия разрешает только некоммерческое исследовательское
использование, поэтому в репозитории её нет. Она скачивается из официального релиза InsightFace при первом
запуске (или командой `python download_models.py`; проверяется SHA-256, из архива в 127 МБ берётся один файл).
Автоскачивание отключается ключом `--no-download`.

| Файл | Размер | Назначение | В репозитории |
| --- | --- | --- | --- |
| `face_detection_yunet_2023mar.onnx` | 0.2 МБ | детектор лиц | да |
| `face_landmarker.task` | 3.6 МБ | глаза, взгляд, мимика, поза головы (MediaPipe) | да |
| `human_faceres.onnx` | 13.3 МБ | узнаваемость, пол/возраст (необязательно) | да |
| `nima_mobilenetv2.onnx` | 12.3 МБ | эстетика лица (необязательно) | да |
| `w600k_mbf.onnx` | 13.0 МБ | ArcFace: группировка по людям | **нет**, скачивается при первом запуске |

Источники и лицензии всех моделей: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md) (тексты лицензий — в [licenses/](licenses/)).
**Важно:** `w600k_mbf.onnx` — только для некоммерческого использования; для коммерческого замените её на модель
с подходящей лицензией.

Без NIMA и FaceRes программа работает (`nima`/`faceres` в `config.yaml` можно указать как `null`).
Без FaceRes метрика узнаваемости считается по ArcFace.

## Запуск

```bash
python best_face.py "путь/к/папке/с/фото" [--output папка] [--limit N] [--no-contact-sheet] [--no-cache]
                    [--choices manual_choices.json] [--no-download] [--config config.yaml]
```

| Ключ | Что делает |
| --- | --- |
| `--output папка` | куда сохранить результат (по умолчанию `<папка_с_фото>/best_face_output`) |
| `--limit N` | обработать только первые N фото (для проверки настроек) |
| `--no-contact-sheet` | не строить HTML-контактный лист (быстрее) |
| `--no-cache` | не использовать кэш обработанных кадров |
| `--choices файл` | применить ручной выбор лучших кадров из контактного листа (можно вместо папки передать сам `manual_choices.json`) |
| `--open` | после завершения открыть папку с лучшими фото |
| `--no-download` | не скачивать недостающие модели автоматически |
| `--config файл` | использовать другой файл настроек вместо `config.yaml` |

По умолчанию результаты сохраняются в `<папка_с_фото>/best_face_output/`.

Для удобства:

- **Windows:** перетащите папку с фото на `run.bat` (или файл `manual_choices.json` для применения ручного выбора).
- **macOS:** двойной клик по `run.command` (откроется выбор папки).
- **Linux:** `./run.sh "путь/к/папке"`.

На macOS и Linux один раз выполните `chmod +x run.sh run.command`.
При первом запуске (`run.bat`, `run.sh`) скрипт сам создаст `.venv` и поставит зависимости из `requirements.txt`
(нужны Python 3.10+ и интернет); если `requirements.txt` изменится, зависимости доустановятся при следующем запуске.
Если модель `w600k_mbf.onnx` не удалось скачать (нет интернета), программа завершится с кодом 2 и подсказкой: повторите запуск с интернетом или положите файл в `models/` вручную.
